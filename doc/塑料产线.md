# 塑料产线 plastic_line

> ⚠ **部分验证：气通了、能产出，产能没达标。** 结构、几何、真机落地都过；
> 60 秒 `by_product: {plastic-bar: 18}`，理论 120，**15%**。别当它能用。
>
> 工具 `bp_plastic_line` 的回包带同样的标注。

## 结构

化工厂（3×3）一排，液口在北侧两个**角格**（朝北，进料）和南侧两个角格（朝南，出料）。

    py-4  气主管 ────────────────  端口 (-1, py-4)
    py-3  地下管入口（朝北接主管）
    py-2  煤带 ──────────────────  端口 (-1, py-2)
    py-1  地下管出口（朝南）＝ 角格液口要接的那一格；煤臂在中间格
    py..py+2  化工厂
    py+3  取塑料的臂
    py+4  塑料带 ────────────────  端口在东端

气走**地下管跨越煤带**（跨度 2）：主管在上、入口朝北、出口朝南，三段才连得起来。

**端口落点由 `machine_fluid_ports` 推导，不许手摆坐标。** 手摆那次把地下管出口摆到了
化工厂自己占的格子上，隧道一路钻到机器底下、游戏不报错、气就是不通——这条坑见
`doc/蓝图格式与坑.md` 5.7。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `target_rate` | 2.0 | 目标塑料/秒；台数由 `machine_count` 从真值表算（`target_rate=4` → 两台化工厂、48 实体） |
| `machine` | `chemical-plant` | 化工厂 |
| `belt` | `fast-transport-belt` | 内部带档位 |
| `gap` | 2 | 相邻两台化工厂之间的空格数 |

## 实测（两台化工厂，60 秒）

    48 实体 | lint 0 error / 0 warning / 0 note | 真机落地 48/48，0 影子
    夹具自动接上 petroleum-gas（infinity-pipe）+ coal（带）
    by_product: {plastic-bar: 18}   ← 理论 120，15%
    两台化工厂流程正常

## 卡在哪：煤没到炉子

煤线的终点落在 4 个收货钢箱里（各装 171 / 170 / 168 / 152 块煤），
而 y=−2 那条进料带是**空的**——煤被当成成品收走了。
形状和绿板那次「把铜线带当成输出口」一样：**夹具把内部带当成了产物带**。
夹具修好之前，这条线的产量读数不算数。

## 为它新增的能力

`bp_testbench` 现在认**流体端口**：端口里的物品是 fluid 时走 `infinity-pipe` 直灌，不走带子。
没有这条，塑料连自测版都生成不出来。
