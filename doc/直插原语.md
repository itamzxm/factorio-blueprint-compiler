# machine_pair：机器对机器直插

> 代码 `bpcompile/primitives.py`｜速率表 `INSERTER_RATE`

## 它是什么

Factorio 里最基本的单元之一：上位机器的产物用快臂直接被下位机器取走，中间不过传送带。

    [上位 3x3][臂列][下位 3x3]

臂 direction=12：取货朝西（上位），放货朝东（下位）。

## 吞吐核算是硬约束

    INSERTER_RATE = {inserter: 0.83, long-handed: 0.83, fast: 2.31, bulk: 5.6}  # 个/秒/根

不够就当场抛错：

    1 根 fast-inserter 只有 2.31 个/秒，而一台 assembling-machine-1 做 electronic-circuit
    每秒要 3.00 个——搬不动。加臂（一侧最多 3 根，上限 6.93/秒）或换更快的臂。

3 根快臂 = 6.93/秒 ≥ 3.00 需要 → 通过。

这条是这套原语最值钱的地方：它把「搬不动的那个东西不会报错，只会让上游堆满」
变成一次**编译期失败**。

## 已知缺口（诚实版）

直插只解决「两台机器之间」的交换，不解决上位机器的进料。上位机器自己还要一条输入带，
而下位机器的北侧已经被上位机器占了——一个 3x3 机器只有 4 个面，直插占掉一个，
「上位进料」和「下位铁板进料」会抢剩下的面。

用 `row_station` 拼绿板线时撞到的具体冲突：

    下位机器的北面 = 自己的输入带（铁板）
    上位机器在下位机器西侧 → 它的北面同样是「北面那一行」，
    但那一行已经被下位的铁板带占了 —— 上位机器没有面可以进料。

正解要么给上位机器单独一层带（两行带，像炉子阵列的「进料带 + 燃料带」那样上下叠），
要么把上位机器的进料也走直插（链条再往上一层）。两者都还需要一层布局抽象，这一版没做。
