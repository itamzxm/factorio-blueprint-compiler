# `furnace_array`：目前唯一真正能用的模板

> 这是**交付物**，不是笔记。参数、端口、当积木用、自测版、验证读数，都在这一页。
> 代码：`bpcompile/templates/furnace_array.py`｜工具：`bp_furnace_array`

## 它造出来是什么

一排炉子，北面两条独立输入带（进料 / 进燃料），南面一条出成品带。臂朝向、供电、铜线全部算好。

    y = -3      燃料带  ────────────────────────→   （只有烧固体燃料的炉子才有这行）
    y = -2      进料带  ────────────────────────→
    y = -1      [短臂取料][长臂跨过进料带取燃料]  ×N
    y = 0..fh-1 炉子 ×N（紧挨着排，fh = 炉子高度）
    y = fh      [短臂从炉子取成品]
    y = fh+1    出成品带 ────────────────────────→

- 2×2 炉子（石炉/钢炉）：7 行。3×3 炉子（电炉）：7 行。
- 宽度 = `count × 炉子边长 + 1`（再 +1 是出成品带尾那一格）。
- 燃料那一路用**长手臂跨过进料带**取料——长手臂取货距离 2 格，正好越过一格带。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `count` | 24 | 台数 |
| `furnace` | `stone-furnace` | `stone-furnace` / `steel-furnace`（烧燃料）或 `electric-furnace`（要电、没有燃料带）。2×2 或 3×3 |
| `input_item` | `iron-ore` | **喂什么**。给 `output_item` 时可不填，会自动从 smelting 配方反查 |
| `output_item` | 由 input 推导 | **出什么**，也是验收时比的物品名 |
| `belt` | `fast-transport-belt` | 带档位。默认快带是量出来的：24 台从西端单口喂，黄带 60 秒 277 块（低于 300 的验收线），快带 326 |
| `inserter` / `long_inserter` | `inserter` / `long-handed-inserter` | 臂档位 |
| `pole` | `medium-electric-pole` | 电塔档位。中塔供电 3.5 格，正好一排在 y=fh 行覆盖两侧臂 |
| `label` | 自动 | 蓝图名 |

⚠ **炉子实体上不写 `recipe`。** 游戏自己导出的炉子蓝图里就没有这个字段；写了也不生效，
产物由进料决定。所以参数是"喂什么 / 出什么"，不是配方。
（`foundry` 那种 `type=assembling-machine` 的机器才写 recipe。）

## 端口（接线口）

返回里给三个格坐标，都是**空格子**，玩家在自己那边接带：

| 键 | 含义 |
|---|---|
| `feed_input_cell` | 进料带西端（带往东流）。接你的原料带 |
| `fuel_input_cell` | 燃料带西端。烧燃料的炉子才有；不烧燃料时为 `null` |
| `product_output_cell` | 成品带东端下游那一格。接你的出料带 |

旧名字 `ore_input_cell` / `coal_input_cell` / `plate_output_cell` 还留着当别名。

这些端口同时登记在 `Blueprint.ports` 里，带 `direction`（物流方向）和 `item`（走什么物品）——
**自测版靠这两个字段自动接夹具**。注意：端口信息**不进蓝图串**，`bp_load` 之后要重新 `bp_declare_port`。

## 当积木用（拼到更大的线里）

三种拼法，都不需要改模板：

1. **串行**：把 A 的 `product_output_cell` 接到 B 的 `feed_input_cell`。中间自己铺带，
   B 的 `input_item` 填 A 的 `output_item`。
2. **并行**：同一个 `input_item` 建两个阵列，进料带从同一个来源分叉（需要分流器——**生成侧还没有分流器原语**，
   现在只能手工 `bp_add_entity` 补）。
3. **当中间品工厂**：只取它的 `product_output_cell`，下游自己接。注意它的**产能**要自己算：
   每台炉子 `60 / (配方耗时 / 炉子速度)` 个成品/秒。石炉炼铁 = 0.3125/s/台。

要放位置：模板总是从 x=-1、y=-3 起摆。要在别处放，先 `bp_new` 建一张临时的、生成后再整体平移
（现在没有平移原语，只能改坐标重建）。

## 自测版：怎么量产量

    bp_furnace_array(count=24)                   # 玩家版，端口自带 direction + item
    bp_testbench(seconds=60)                     # 出「自测版」：夹具全接好，单独一个文件
    bp_verify(modes="lint,run", run_seconds=60)  # 真跑 60 秒，读 produced / drained

夹具三件套（细节见 `doc/自测版夹具.md`）：

- 输入口 → `infinity-chest`（filter + at-least 200）＋ **4 只臂** → 带上
  （一只快臂只有 ~2.3 物品/秒；24 台石炉要 7.5 矿/秒，一只喂不动）
- 输出口 → 4 只臂 → **钢箱**（不用 infinity-chest：它会把货吞掉，累计数就读不出来）
- 电网 → `electric-energy-interface` 就近并网

夹具是 hidden 原型，正常游戏造不出来——**自测版单独出，不要发给玩家**。

## 验证读数（真机，可复现）

| 配置 | 结果 |
|---|---|
| **24 台石炉，60 秒** | 落地 300/300；`produced 330` / 理论 450 = **73.3%**；`drained {"iron-plate": 326}`；24/24 working。**连跑三次逐项一致** |
| 24 台石炉，120 秒 | `produced 778` / 900 = 86.4%（稳态约 86%；60→120 秒的差全是坡道时间） |
| 24 台石炉，黄带 60 秒 | 277（低于 300 验收线——这就是默认换快带的原因） |
| 玩家版 `examples/furnace24.blueprint.txt` 60 秒 | 377（不同文件，也稳定） |

⚠ **引用数字必须带口径。** 夹具本身也会坏：有一版夹具改坏了喂矿链路，同一张图掉到 176、
16 台炉子饿着；修好后回到 330。判"是我的问题还是夹具的问题"看三条：蓝图几何有没有动、
连跑两次是否完全相同、**把夹具臂 4→8 产出变不变**。

复现：

    python tools/factorio_build_check.py examples/furnace24.testbench.blueprint.txt --run-seconds 60

**读数的规矩：先看 `drained` 的物品名，再看数量。** 数量对、物品错是这类项目最贵的错。
