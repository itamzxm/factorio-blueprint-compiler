# 绿板产线 green_circuit

> 代码 `bpcompile/templates/green_circuit.py`｜工具 `bp_green_circuit`｜底层原语 `row_station` + `machine_pair`
>
> ✅ **过了验收线。** 默认参数 102 实体，60 秒绿板 **107 个**（验收线 60），5 台机器全部 working。

## 结构：横向交替 + 直插

    面预算（这是设计的核心约束）
      铜线机：北（进铜板）+ 东（直插出铜线）            = 2 张面
      绿板机：北（进铁板）+ 西（直插接铜线）+ 南（出绿板） = 3 张面

    行结构
      y-2  铜板带  ────────────────────────────────
      y-1  铁板带  ────────────────────────────────
      y0   臂：铜线机上方是长臂（跨过铁板带取铜板），绿板机上方是快臂（取铁板）
      y1..y3  [铜线机] [臂列] [绿板机]   [铜线机] [臂列] [绿板机]
      y4   取绿板的臂
      y5   绿板带  ────────────────────────────────

两台机器的进料都在北侧，直插走东西向，输出走南侧——每一层都有面，不用把带子往上叠，也不用把链条再抬一层。
直插原语见 `doc/直插原语.md`。

端口（默认参数、origin=(0,0) 时）：`copper_input_cell (-1,0)`、`iron_input_cell (-6,1)`、`circuit_output_cell (19,7)`。

## 配比 3:2，不是 1:1

    铜线机 2 个/秒 × 3 = 6/秒；绿板机满负荷 3 铜线/秒 × 2 = 6/秒 —— 正好平
    一对一是 2 : 3，上限只有 67%

所以台数是 `n_cable = ceil(1.5 × n_circuit)`：默认 `target_rate=2` → 2 台绿板机 + 3 台铜线机。

## 吞吐核算

    INSERTER_RATE = {inserter: 0.83, long-handed: 0.83, fast: 2.31, bulk: 5.6}  个/秒/根
    直插 3 根快臂 = 6.93/秒 ≥ 绿板机满负荷 3 铜线/秒  → 通过
    直插 1 根     = 2.31/秒 < 3.00/秒                → 抛错「搬不动」

## 已知的两个坑（都已写进代码注释）

1. **铜线带方向**：早期版本铜线带往东流，落在东边的铜线永远回不到上游取料格——能建、lint 干净、绿板机永远缺料。
2. **两个输入端口不能挨着**：两条进料带只隔 1 行，端口放在同一处时夹具会互相抢格子，实测表现为铁板进不来、绿板 0 个。所以铁板带往西错开 5 格。
