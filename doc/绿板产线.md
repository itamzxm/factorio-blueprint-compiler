# 绿板产线 green_circuit

> 代码 `bpcompile/templates/green_circuit.py`｜工具 `bp_green_circuit`｜底层原语 `primitives.row_station` + `machine_pair`
>
> ⚠ **未通过验收线。** 结构、lint、真机落地都过，60 秒绿板 **26 个**（验收线 60）。

## 结构：横向交替 + 直插

    面预算（设计核心）
      铜线机：北（进铜板）+ 东（直插出铜线）            = 2 张面
      绿板机：北（进铁板）+ 西（直插接铜线）+ 南（出绿板） = 3 张面

    行结构
      y-2  铜板带
      y-1  铁板带
      y0   臂：铜线机上方是长臂（跨过铁板带取铜板），绿板机上方是快臂（取铁板）
      y1..y3  [铜线机][臂列][绿板机] ... 每对 7 格宽
      y4   取绿板的臂
      y5   绿板带

两台机器进料都在北侧、直插走东西向、输出走南侧，所以每一层都有面，不用再叠带子。
直插原语见 `doc/直插原语.md`。

## 吞吐核算

    INSERTER_RATE = {inserter: 0.83, long-handed: 0.83, fast: 2.31, bulk: 5.6}  个/秒/根
    直插 3 根快臂 = 6.93/秒 ≥ 绿板机满负荷 3 铜线/秒  → 通过
    直插 1 根     = 2.31/秒 < 3.00/秒                → 抛错「搬不动」

## 实测（60 秒）

    built 109/109，ghosts 0，lint 0 error / 0 warning / 2 note
    by_product: {copper-cable: 71, electronic-circuit: 26}
    machine_status: full_output 3 / item_ingredient_shortage 3

**验收线是 60 个绿板，实测 26 个（0.43/s），没到。**

诊断：铜线机 `full_output`（铜线堆满送不出去）+ 绿板机 `item_ingredient_shortage`。
铜线堆着的同时绿板机还饿着 → 缺的是**铁板**，不是铜线。
下一步查铁板夹具：为了避开两个端口抢格子，铁板带往西多伸了 5 格，
带子变长、夹具可能供不上。

## 已知的两个坑（都已写进代码注释）

1. **铜线带方向**：早期版本铜线带往东流，落在东边的铜线永远回不到上游取料格——
   能建、lint 干净、绿板机永远缺料。
2. **两个输入端口不能挨着**：两条进料带只隔 1 行，端口放在同一处时夹具会互相抢格子，
   实测表现为铁板进不来、绿板 0 个。所以铁板带往西错开 5 格。
